# Кнопка AI Assistant в левой панели Р7

Фоновый системный плагин для установленной версии Р7 с единой панелью визуальных плагинов. Добавляет одну кнопку возле штатной кнопки плагинов в текстовом редакторе. Загружает иконку из основной установки AI Assistant. Не открывает AI Assistant при загрузке документа.

Нажатие запускает основной плагин через `asc_pluginRun` в том же редакторе. Если его панель уже загружена, кнопка скрывает или показывает её без перезапуска. Штатная блокировка кнопки плагинов распространяется на новую кнопку. Содержимое документа не меняется.

Установка обоих компонентов: `node scripts/install-dev.mjs` из корня решения. После установки заново откройте документ, чтобы Р7 загрузил системный плагин. Основная кнопка на вкладке «Плагины» сохраняется.

Интеграция зависит от интерфейса установленной версии Р7 (`#left-btn-plugins`, `DE`, контроллер `LeftMenu`). Современный механизм отдельных панелей ONLYOFFICE здесь не используется: установленный Р7 его не реализует. При отсутствии нужных элементов кнопка не добавляется. Для удаления расширения удалите только установленную папку `{26AD9633-DE82-4527-9B0B-7D5BE6419CA7}` и заново откройте документ.

Изменение установлено без запуска проверок по указанию пользователя. Отображение и нажатие в живом Р7 пока не подтверждены.
