# Изменение продукта

**Потребность.** Использовать AI Assistant в Р7 с GigaCowork без отдельного процесса Bridge, сохранив существующую редакторскую панель и сценарии обработки.

**Реализация.** Плагин GigaCowork владеет локальным сервером, хранилищем сессий и системным помощником. В одном процессе рабочие области используют общий сервер и один принимающий чат. Выбор чата и остановка приёма управляются инструментами GigaCowork. Сессия и claim исходной задачи сохраняются на всех этапах. Для подключения панели проверяется процесс Р7, которому принадлежит локальное TCP-соединение.

**Интерфейсы.** Панель сохраняет локальный HTTP, MCP сохраняет HTTP-транспорт. Разработка и регистрация Host отделены от исходного AI Assistant. Жизненный цикл отдельного приложения в трее заменён жизненным циклом GigaCowork, диагностика доступна через HTTP, установку Р7 можно выбрать в конфигурации Host.

**Приёмка.** Проверки встроенного запуска и завершения, маршрутизации задач, форматов результатов и прав доступа входят в `npm test`. Для продуктовой приёмки нужен запуск установленного GigaCowork и синтетического документа Р7 с реальной моделью.
